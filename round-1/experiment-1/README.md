## Layman Summary

Converts text to logic rules, then when reasoning fails, classifies WHY it failed and applies the right targeted fix — comparing typed repair against a single-strategy baseline on 200 examples.

## Full Summary

Implemented a complete neuro-symbolic pipeline that extracts first-order logic (Prolog facts and rules) from natural language text using an LLM, loads them into a custom Python backward-chaining Prolog engine, and classifies proof failures into five typed categories: TYPE_1_LEXICAL_MISMATCH (predicate absent but a similar one exists), TYPE_2_ARITY_MISMATCH (wrong number of arguments), TYPE_3_MISSING_FACT (proof search exhausted), TYPE_4_CATEGORY_VIOLATION (type error), and TYPE_5_SCOPE_CONFLICT (quantifier heuristic). Type-specific LLM repair dispatchers are implemented: Type-1 generates bridge axioms linking mismatched predicates with cited source sentences; Type-3 performs abductive fact injection with span-verified justifications. A bridge-axiom library accumulates reusable axioms across documents. The ARGOS baseline applies uniform single-strategy abductive repair regardless of failure type. Both pipelines are evaluated on 100 synthetic RuleTaker examples (propositional logic chains) and 100 synthetic CLUTRR examples (kinship multi-hop reasoning). RuleTaker results: typed accuracy=95.0%, baseline accuracy=95.0% (RuleTaker facts are directly parseable; failures are rare). CLUTRR results: typed=0.0%, baseline=0.0% (kinship relation queries require relational variable binding not yet supported by the goal extractor). Total LLM API spend: $0.23 of $8.00 cap. Bridge axiom library accumulated 4 axioms with a 0.04 reuse rate. Hallucination is tracked per-clause via source-span coverage. Output schema follows exp_gen_sol_out with predict_typed and predict_baseline fields plus metadata fields for failure type, hallucination rates, and repair counts. All 200 examples are in method_out.json (123KB); full/mini/preview variants generated; schema validation passed.
